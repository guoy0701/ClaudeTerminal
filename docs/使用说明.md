# ClaudeTerminal 使用说明

> 适用版本：v3.7.0 · 2026-07-20 更新
>
> ClaudeTerminal 是 Claude Code 的桌面图形客户端：终端的外观和手感，加上真正的图形能力——
> 多标签并行会话、可折叠消息流、多账号切换、灵动岛悬浮窗、定时自动化与无人值守续跑、跨会话搜索。
> 会话数据与官方 `claude` 命令行完全互通。

---

## 1. 安装与首次启动

1. 运行安装包 `ClaudeTerminal-Setup-x.x.x.exe`，一路下一步即可。
2. **前提**：本机已安装官方 Claude Code 并登录过（终端里运行过 `claude` 并完成认证）。
   没登录过的话，首次启动会有认证引导，按提示在终端执行 `claude login` 后回来即可。
3. 应用启动后出现**启动屏**：
   - 选择**工作目录**（就是你要让 Claude 干活的项目文件夹，默认记住上次的）；
   - 「**跳过权限确认**」勾选框：勾上 = 工具调用不再逐条询问（等价官方 `--dangerously-skip-permissions`）；
   - 下方列出该目录的**历史会话**，点一条即可接着上次聊。
4. **自动更新**：新版本发布后启动时自动提示；也可以随时点菜单「帮助 → 检查更新」。
5. **重复打开不会开两个窗口**：再次双击图标，只会聚焦已打开的窗口并弹出选目录开新标签。
   关闭窗口是**最小化到托盘**（长任务继续后台跑），真正退出用托盘右键「退出」或 Ctrl+Q。

## 2. 快捷键速查（最常用的先记这几个）

| 快捷键 | 作用 |
|---|---|
| **Enter / Shift+Enter** | 发送 / 换行（输入多了输入框会自动长高） |
| **Shift+Tab** | 循环切换权限模式（含 Bypass 自动档，见 §4） |
| **Ctrl+F** | 搜索**当前会话** |
| **Ctrl+Shift+F** | 搜索**所有历史会话**（启动屏也能按，见 §5） |
| **Esc** | 运行中 = 中断；空闲 = 清空输入；**双击 Esc** = 回撤到之前某轮 |
| **Ctrl+Tab · Ctrl+1~9** | 切换标签页 |
| **Ctrl+O** | Transcript 全文回看（原样查看整场对话） |
| **Ctrl+S** | 导出对话为 Markdown |
| **?** | 输入框为空时按 `?`，弹出应用内快捷键速览 |

其余：`↑↓` 翻输入历史（Ctrl+↑↓ 按轮次跳）、`Ctrl+R` 反向搜历史输入、
`Ctrl+G` 文件变更面板、`Ctrl+B` 后台任务、`Ctrl+Shift+O` 全部折叠/展开、
`Ctrl+=` / `Ctrl+-` / `Ctrl+滚轮` 缩放字体、`F11` 全屏。

## 3. 输入框的四个前缀

在输入框开头输入这些字符会进入特殊模式（和官方终端一致）：

| 前缀 | 作用 | 例子 |
|---|---|---|
| `/` | 命令菜单（见 §10 命令表） | `/model opus` |
| `@` | 引用项目里的文件（带补全；不打 @ 直接按 Tab 也能补全路径） | `@src/main.ts 这里有个 bug` |
| `!` | 直接执行本地终端命令，输出进入对话 | `!git status` |
| `#` | 把一句话存进项目记忆（CLAUDE.md） | `#这个项目用 pnpm` |

输入框支持 **Ctrl+V 粘贴图片**（截图直接贴进来问）。

## 4. 权限模式：什么时候要我点「允许」？

底部状态栏有一个**模式徽章**，按 **Shift+Tab**（或点徽章）循环切换：

| 模式 | 行为 |
|---|---|
| **default** | 写文件、跑命令等敏感操作，每次弹卡片问你（可选「总是允许」，规则会持久化，官方终端也认） |
| **acceptEdits** | 编辑类操作自动放行，其余仍询问 |
| **plan** | 只做计划不动手，计划出来后弹「计划卡」等你批准 |
| **bypass** | 全自动，不再询问（**首次切入会弹一次确认**，之后本次运行不再问） |

弹出卡片时的键盘操作：权限卡 `y` 允许 / `a` 总是允许 / `n` 拒绝；
Claude 提问的选择卡按 `1~4` 选、`Enter` 提交、`d` 展开详说。

## 5. 搜索：找回任何一次聊过的内容

- **Ctrl+F**：搜当前会话，高亮跳转。
- **Ctrl+Shift+F**：**跨会话全文搜索**。扫描本机全部历史会话（包括你在官方终端里聊过的），
  输入两个字以上即开始搜；`↑↓` 选择、`Enter` 或点击 → 直接**新标签恢复那次会话**接着聊。
  在启动屏就能按——想找回上周聊过的东西，打开应用直接搜。

## 6. 标签页：多个会话并行（v3.25.0 起是「工作台」）

- 标签栏 `+` 打开和首个窗口一样的启动页：选目录新开会话，或直接点下面的**历史会话**在新标签里恢复。`Esc` / 右上 `×` 取消。
- 每个标签是完全独立的会话，后台标签照常运行。**Ctrl+Tab** 轮换、**Ctrl+1~9** 直达；`/exit` 或关标签结束该会话。
- **拖动排序**：按住标签左右拖。同一组里按标签挪；拖到别的组上，整组一起挪（组不会被拖散）。
- **同文件夹自动成组**：同一个文件夹开了两个以上标签（比如缓存过期后新开一个接着干），它们自动排在一起，前面有个彩色组名和数量。点组名折叠 / 展开（正在看的那个标签不会被折起来）；拖组名可整组移动。
- **标签多了自动变窄**：按比例缩到最窄约 64px，`+` 永远在最右边看得到；再放不下时，在标签区滚轮可以左右滚。
- **右键标签**：重命名（改过名后不会再被自动改名覆盖）、恢复自动标题、加入 / 移出活跃、关闭。
- **当前标签**（v3.26.0）：更亮的底色、标题加粗、底边一条绿线，一眼能看出当前页面对应哪个标签。
- **只看活跃的标签**（v3.26.0）：「工作 | 计划」右边有「**全部 | 活跃**」切换。切到「活跃」只显示：正在跑的、跑过还没移出的、你手动加入的，以及正在看的那个；其余（比如重启恢复出来、还没用过的历史标签）收进右边的「**+N**」，点开选一个就加入活跃并打开。
  - 标签一开始运行（发消息、计划到点发车）就**自动加入活跃**，跑完了还留着；在别的标签时它跑完了，标签上亮一个**绿点**（刚跑完、还没看），切过去看一眼就消。
  - 看完了右键「**移出活跃**」（或直接关掉）；也可以右键「**加入活跃**」手动钉住。这次新开的标签默认在活跃里。
  - 名单、绿点和当前是哪种视图，重启后都保留。计划为续缓存发的「保温」消息不算运行，不会把标签拉回活跃。
- **引擎自动续写**（v3.26.0）：回复流中途断了（网络 / 服务端），引擎会自动发一句英文「Your response above was cut off mid-stream…」让模型接着写。这不是你发的，也不是模型乱回——现在显示成一行灰色中文备注「↻ 回复流中途断了…」，不再像你发的消息，也不再另算一轮。
- **「✻ … · done 20:47」的时刻**（v3.26.0）：按这一轮真正结束的时刻显示（以前用「开始 + 耗时」推算，碰上流中断续写会算出一个还没到的时间）。本应用自己的会话恢复后也有这一行；停在工具中途（被中断 / 崩溃）或以报错收尾的轮不显示。
- **关掉 / 重启后原样恢复**：标签、顺序、名字、分组、压缩档都记着，下次打开原样出现，除非你自己关掉那个标签。恢复出来的标签是「休眠」的——不起引擎、不发消息、不花 token；**点到哪个才连哪个**（打开时的活动标签立即连上）。对话记录从会话记录里回放，每轮的开始时刻和「✻ … for 50s · done 20:47」都在。
- 系统提示卡（切换账号、重启会话、界面已重载等）只是一张卡，不会变成标签名，也不占右侧轮次号。
- 同一账号的标签共用该账号额度（5 小时窗口是账号级的）；不同账号的标签各用各的，见下一节。

## 7. 多账号：几个 Claude 账号轮着用

点底部状态栏的**账号区**打开账号菜单：

- 上半部分显示**当前标签页**正在用的账号；下半部分「新标签页将使用」列出全部账号档案，
  点选即设为**新标签页的默认账号**（已打开的标签不受影响——每个标签创建时就绑死账号，避免缓存串号）。
- **+ 添加账号**：浏览器打开官方授权页登录，回来粘贴页面显示的授权码即可，全程不消耗 token；
  授权链接可复制到其他浏览器完成。
- **管理账号…**：具名账号有「重新登录」和「移除」（有标签页正在用时会先确认关闭这些标签页再移除）。邮箱相同的具名账号视为同一个账号，会自动合并成一行；
- **与官方终端隔离（v3.20.0）**：列表里标着「**（跟随官方终端）**」的那一行，是官方终端（`~/.claude`）此刻登着的账号。ClaudeTerminal 对它**只读跟随**：不能在这里登录、重新登录或登出，要换号请在官方终端里 `/login`。这样在 ClaudeTerminal 里怎么切账号、登账号，都不会把官方终端正在跑的账号一起换掉。想在 ClaudeTerminal 里固定用某个号，用「+ 添加账号」把它加成具名账号（有自己的目录）。官方终端换号后，被顶掉的那个账号会自动转成具名账号保留下来。
- **重新登录授权错号会自动撤销**（v3.20.0）：浏览器里 claude.ai 登的是 A、却在 B 那一行点了「重新登录」，授权会被判定为错号，B 这一行保持原样，并提示你先在 claude.ai 切到 B 再试。
  档案出现「未登录」徽标时按提示处理即可。
- **附加账号看到的规则与官方一致**：每个附加账号的档案目录会联接主目录的 projects、todos、plugins、skills、agents、commands、hooks，
  并同步 settings.json 与全局 CLAUDE.md，所以子代理定义、自定义命令、hooks、memory 在任何账号的会话里都可见（v3.12.2 起；此前附加账号
  看不到 CLAUDE.md 和 agents，子代理规则在该账号下失效）。出现「降级·缺规则/记忆」徽标说明联接失败，该账号会话可能缺这些内容，重启终端会重试接管。
- **额度分桶**：状态栏/灵动岛显示的 5 小时窗口跟随当前标签的账号——A 账号跑满了，
  开个 B 账号的新标签接着干。

### 7.1 账号管理页（v3.14.0）

账号菜单里的「管理账号…」现在打开一个**全窗口的账号页**（Esc 关闭），三栏：

- **左栏**：按提供方分组（Anthropic / CodeBuddy / 第三方 API），每行带状态灯（在线 / 未登录 / 需重登）。底部「+ 添加账号」。
- **中栏**：身份卡（提供方、邮箱、订阅、重新登录 / 登出 / 移除）、额度面板（Claude 账号显示 5 小时与周窗口两条进度条和重置倒计时）、该账号可用的模型清单。
- **右栏**：哪些标签页正在用这个账号（点击可跳过去）、以及把它当子代理调用的示例。
- 顶部一排胶囊是全部账号的周剩余百分比总览。

### 7.2 接入腾讯 CodeBuddy / WorkBuddy 的免费模型（v3.14.0）

ClaudeTerminal 通过腾讯**官方**的 `codebuddy` 命令行接入（不是逆向反代，不伪造任何请求头，账号安全与官方客户端一致）。

1. 先装并登录一次：`npm i -g @tencent-ai/codebuddy-code`，然后在终端运行 `codebuddy`，输入 `/login` 完成浏览器登录（CodeBuddy 与 WorkBuddy 共用同一账号和积分）。
2. 账号页「+ 添加账号」→ 选 **CodeBuddy** → 起个名字 → 点「检测」变为在线即可。
3. 之后在**任何**标签的对话里，Claude 都能调用 `ask_account` 工具，把一段任务交给该账号的 GLM / Kimi / GPT / Gemini 等模型作为**只读子代理**执行并拿回结果，例如：「让 CodeBuddy 用 kimi-k3 审一下我刚改的这个文件」。子代理默认只能读工作区、不能改文件，同一标签内串行执行。
4. CodeBuddy 各模型有各自的频率限制，连续跑重任务会返回 429 并给出重置时间，换一个模型即可继续。

- 恢复**别的账号**聊过的历史会话时会弹确认（标明归属账号和预估 token 成本），不会悄悄烧额度。

## 8. 灵动岛：不切窗口盯进度

屏幕上有一个小悬浮胶囊（可在菜单「查看 → 灵动岛」开关），始终置顶：

- **看状态**：像素宠物/色点表示运行中、完成、出错、提问中；旁边显示缓存倒计时等信息；
  多个标签时右侧有数字徽标。
- **轻点胶囊**：展开**多会话面板**——每行一个标签页（状态色点 + 名称 + 运行耗时/等待确认），
  点某行 → 主窗切到该标签并聚焦；最下面一行「打开主窗口」。
- **直接在岛上应答**：Claude 提问时选项直接出现在岛上，点选即答；
  权限请求可直接「允许 / 拒绝」，计划卡可直接「批准执行」——不用回主窗口。
- **按住拖动**可把岛挪到任意位置；「查看 → 灵动岛」里可关像素宠物（变极简条）和 8-bit 音效。

## 9. 自动化：定时任务与无人值守

> **总览里点已经发出去的消息**（v3.25.0）：双击块、右键「打开对话」或详情栏「打开对话 ›」直接到真实的工作聊天窗口——标签还开着就切过去，关了就恢复那个会话（只打开、不发消息），和大模型的全部交互都能看到。要看这一路的计划，用右键「查看这一路的计划」。

### 9.0 计划（v3.23.6：路 × 消息 × 触发关系）

打开 ClaudeTerminal 默认进入**计划·总览**；点「工作」回到工作区（还没有标签时是启动卡片）。标签栏最左边是「**工作 | 计划**」两段式开关，选中的一边是实心色块；数字分别是开着的工作标签数和还没发车的路数。点「计划」切过去，同一条标签栏换成第二层：**▦ 总览** + **每一路一个标签（#1、#2……）**。Esc 或点「工作」回到工作标签。也可以输入 `/automation`，或托盘「打开计划…」进入。

**一路 = 一个标签 = 一个文件夹 = 一个会话。** 路和路互不影响。编号按新建顺序给，只有你拖动标签才会变；删掉的路就没了，后面的编号顺延。

**一路里可以排好几条消息**，每条选一个触发方式：

- **⏰ 定时**：到某个时刻发；
- **⛓ 上一条之后**：同一路第 2 条起默认用这个；
- **⛓ 等别的路某一条之后**：触发条件可以看别的路、别的账号跑得怎么样（消息本身永远在自己那一路）。

后两种各自下面再选（分层显示；「等别的路某一条」要自己挑是哪一条，挑到的是草稿会当场提示「那条不会发，这条会一直等」）：
- 「**它做完了才发（AI 确认）**」（默认）：它停下后，AI 读最后的输出、看有没有后台命令或子代理还在跑，确认活真干完了才发——防止模型嘴上说「接下来我会继续……」却停了。**AI 说没做完就一直等**；停了 30 分钟还没做完会通知你一次，你可以去那个标签让它继续（它一有新动静就重新判断），或在消息上点「**当作做完**」放行后面的。AI 只在有新动静时才判断，不会反复花 token。
- 「**它一停下就发**」：不管干没干完，这一轮一停下（不再输出）就发下一条，不花判断的 token。

想让模型一直推进到某个标准达成，把内容写成 `/goal 你的完成标准`。计划里也可以写 `/compact` 这类命令，到时照常发出；命令这一轮一结束就算完成（不请 AI 判）。

- **总览**分三列：左边是**账号**（同一个邮箱只算一个；官方终端正在用的标「官方终端」；5 小时 / 周额度，登录失效的显示「未登录 · 去重新登录 ›」）；中间是这个账号下的**各路**（第一行「#n 名字」，第二行文件夹名）；右边是**时间轴**。消息是块：定时的在它的时刻，等别人的放在估计时刻（标「≈」）并用虚线连到它等的那条。底色带是预计的 5 小时窗口（同账号几路共用一条），周额度用完到重置前画灰。
  - 账号和账号之间有一条间隔；默认从现在往前留一段，刚发出去的看得见；**已发出的块是实心的**（✓ 完成、● 运行中、✗ 失败），再早的贴在左边缘，不会消失；同一路的几条下面有一条连着的底条（它们在同一个窗口里）；
  - **单击**块 = 选中，下方出详情；**双击** = 打开这一路（已发车的直接切到那个工作标签）；
  - **拖动**定时块改时间；**时间轴**按住空白处左右拖动（或横向滚轮）平移；**滚轮 / 「＋ －」缩放**，放大能看到分钟；「回到现在」复位；
  - 同一路里挤在一起的几条合成一个「N 条」块（带 ✓●✗ 计数），**双击放大**到分得开；
  - **右键**路名或块：打开 / 重命名 / 组颜色 / 删除这一路；
  - 中间的路名**上下拖动 = 调整顺序**（编号跟着变）；拖到别的账号下面 = 换账号（还没发车的才行）；
  - **空白处双击**或顶栏「**+**」= 弹小卡片新建一路（账号、文件夹、名字、第一条什么时候发），建好留在总览并选中它，双击进去写内容（卡片按住标题可以拖开）。新建默认 **Opus 5.5 · effort high · 压缩：终端不压（引擎兜底，同官方）**，进去可改；
  - **组颜色**：路名前的圆点点开选颜色，几路是一组就选同一个颜色；设了「等别的路某一条」时自动与那一路同色；
  - 「**显示过去**」：时间轴向左延伸同样长度，看已经跑过的（运行记录一直保留）。
  - 续跑开关关着、又有要发的消息时，顶上一行「撞额度后自动接着跑：关 [开启]」，点一下就开。
  - 只有「内容写好了、24 小时内要发、但肯定发不出去」（账号未登录、文件夹不存在、周额度没重置）才在块上标红点；没写内容的是草稿，灰色，不提示。
- **路标签**长得和工作标签一样：上面消息区里，待发的消息是灰色气泡，右上角标着触发方式（点它就能改），可以上下移、删除；下面输入框写内容，点发送（或 Ctrl+Enter）——**消息排进上面的列表，到时才真的发**；发送按钮旁的 ▾ 选触发方式。输入框下面 3 行底栏：模型 · effort · 压缩档 ｜ 文件夹 · 账号（只显示，要换账号去总览拖）｜ 全自动（无人值守）。
- **发车**：你正停在某一路的标签上时它发出去了，会直接跳到它的工作标签。一路的第一条发出时，按这一路的设置新开工作标签（无人值守：自动批准计划、不向你提问），之后这一路就是那个工作标签，剩下没发的消息悬停在它的输入框上方。缓存过期时按下面「省 token 规则」处理（不到 100k 直接发，100k 以上先用 Haiku 压再发，不等人）。会话被关掉后恢复，也按这一路设的模型 / effort / 压缩档起。还有写好的消息要等很久才发时，终端会每 50 分钟左右发一条极短的「保温」消息把缓存续上（见下）。
- **错过**：电脑关机或 ClaudeTerminal 没开，过了发送时间 10 分钟以上的，标「已错过」并通知，你决定「现在发送」还是改时间。
- **重复**：路标签右上角可设「每天 / 工作日 / 周末重复」：跑完后按第一条的时刻顺延，新开会话重跑（和别的路有等待关系的路不能重复）。
- **工作标签输入框上方的计划消息可以直接改**：点文字改内容（Enter 保存），点触发标记改时间 / 触发方式，↑↓ 调顺序，× 取消。
- **工作标签里也能排**：输入框右边的 ⏰ 选「定时 / 当前任务之后 / 等别的路某一条之后」，再按 Enter——消息悬停在输入框上方，到时才发（`/at 22:30 内容` 同效）。忙的时候直接发的消息也悬停在输入框上方，这一轮结束后才发出、进消息流。
- 右上角「⚙」是全局设置：续跑开关与策略、缓冲、冷缓存、新标签默认压缩档、引擎兜底线，以及电源 / 防睡眠状态。

升级到 v3.23.0 时，原来的定时任务、队列（编排）和运行中的消息列会自动转成路（原设置备份为 `settings.pre-lanes.json`）；没写内容的草稿、已经执行过的一次性任务不转。后台「锚定」（凌晨发个 1 让 5 小时窗口从早上算起）不变，用 `/anchor` 查看和开关。

**无人值守续跑**：开关打开后，任何标签撞到 5 小时限流，会在额度恢复后（可设缓冲分钟数）
自动发「继续」接着干活。撞到 7 天周限额时：6 小时内就重置的（比如卡在周重置点前后发车），同样等重置后继续；更远的只通知、不自动等（v3.20.0）。
开关关着、却有要发的计划消息时，总览和全局设置都会提醒——计划**不会**绕过这个开关。
goal 评估偶尔失败（网络抖动等）会隔 30 秒、2 分钟、5 分钟各重试一次，都失败才停下并通知（v3.20.0）。v3.7 起可精细控制续跑策略（都在自动化面板里设）：

- **次数上限**：最多自动续几轮，防失控刷额度；
- **截止时刻**：过了这个点就不再续（比如「最晚跑到早上 8 点」）；
- **冷缓存两档**（v3.24.0 起）：**自动省 token**（默认，按下面「省 token 规则」）/ **暂停并通知我**；
- **冷缓存压缩用模型**：缓存已过期（等待超过 1 小时）的那次压缩先切到指定的便宜模型（默认 Haiku 4.5）再 /compact，
  压完自动切回，省下大模型的周额度；缓存尚热的压缩一律用当前模型（热缓存下换模型要全量重读，反而更贵）；
- **自动压缩：两条彼此独立的线（v3.18 起）**，与「限流自动续跑」开关无关：
  - **终端线**（每个标签页一档，底栏「压缩」徽标可单独改）：轮次结束后上下文超过它，终端就趁缓存热发 /compact。
    **推荐**（默认）= 1M 可用窗口在 400k 压、200k 可用窗口不主动压；**不主动压** = 只靠引擎兜底线；**自定义** = 填 `120k` 或 `40%`（不低于 100k）。
  - **引擎兜底线**（设置面板全局一档，会话启动时定）：引擎自带的自动压缩，模型长时间自主工作、迟迟不出轮次结果时的保险。
    **官方默认**（v3.25.1 起为默认）= 模型窗口 −33k，1M 窗口约 967k；**600k 兜底** = 1M 窗口引擎在约 567k 就压；也可自定义。
    ⚠ 兜底线比你设的压缩线低时，引擎会先压——比如设了 800k，兜底 600k 档会在约 567k 就压掉，你设的线永远轮不到。所以默认改成了「官方」；老电脑上保存过的设置不会自动改，要自己到 ⚙ 里改成「官方默认」。
  - 上下文窗口按引擎实测显示（第一轮之后以引擎报的为准），不再按订阅类型自己换算。
    底栏 Context 一行写明「已用 / 窗口 · 压缩线」，压缩线取两条线里先到的那条。
- **冷缓存压缩 effort**：只在冷缓存那次压缩临时换档位。缓存尚热时不换：中途改 effort 会让整段 prompt 缓存失效。同理，
  会话跑着的时候手动 `/effort` 或在档位卡里切档，终端会先弹确认说明成本，防止误触；缓存已过期或空会话不弹。

### 省 token 规则（v3.24.0 起，所有自动路径和手动发送共用一套）

prompt 缓存有效期 1 小时，每次请求续期。缓存热时重读上下文只要 0.1 倍价，冷了要按 2 倍价整段重新写——差二十倍，所以终端围绕「别让缓存白白冷掉、冷了用最便宜的办法」来定规矩：

| 情况 | 上下文 | 你在（手动点发送） | 无人值守（续跑 / 计划 / 定时 / 发进已有会话） |
|---|---|---|---|
| 缓存还热 | 任何 | 直接发；只在到达这个标签的压缩线时压 | 同左 |
| 缓存冷了 | < 50k | 直接发（底栏红字提示） | 直接发 |
| 缓存冷了 | 50k～100k | 弹确认框，默认「直接发送」 | 直接发 |
| 缓存冷了 | ≥ 100k | 弹确认框，默认「先压缩再发（推荐）」 | 用便宜模型先压再发，不等人 |

- **冷压缩用哪个模型（v3.25.0）**：上下文 < 180k 用 Haiku 4.5；≥ 180k（或大小不知道）用 **Sonnet 5**（有 100 万上下文里最便宜的，$2 / $10）。Haiku 只有 200k 窗口，大会话它装不下——实测 734k 用 Haiku 压完还剩 642k，钱花了上下文没降，续发又要整段重写缓存，所以大会话改用 Sonnet 5。设置里「冷缓存压缩用」选的是 Haiku 时自动按这个规则换。

- 确认框写明两种做法各花多少（按 API 价折算的额度）；**5 分钟没人点，就当你不在，按默认处理**。
- 任何**自动**压缩：上下文不到 100k 一律不压（压完还剩约 45k，省不了什么）；手动 `/compact` 不受限制。
- 对所有压缩档都一样，包括「终端不压（同官方）」——那一档只是缓存热的时候不由终端压，到了引擎兜底线由引擎用当前模型自己压，和官方终端一致。
- **冷热按真实时间算**：恢复历史会话 / 重启会话 / 回撤后，距会话记录里上一轮结束不到 1 小时，底栏显示黄色「⚡ 缓存可能还在 · 剩 mm:ss」，按热处理（跨进程恢复实测多数能命中，偶尔没中，这个风险可以接受）；**只有换账号一定是冷的**（缓存按账号分），底栏红色。
- **换模型也一定是冷的**：缓存按模型分，Fable 5.1 和 Opus 5.5 之间来回切，都要整段重读；同一个模型压缩时和原会话共用缓存。
- **恢复会话会对齐模型和 effort**：按会话记录里最后用的模型和 effort 起。模型和 effort 配对：Opus 5.5 默认 high，Fable 5.1 默认 low，不会混用。
- **保温**：只在计划里**确定还有写好的消息**、而且要等到缓存过期之后才发时才做——空闲约 50 分钟发一条极短消息（让模型只回「1」），把缓存续 1 小时。消息区只显示一行灰色「♨ 保温 HH:MM」，不占轮次号；保温那一轮撞了限流也不会触发自动续跑。累计保温花的钱一旦超过「冷了再处理」的花费就停手（单次等待最多 20 次），不会一直停不下来。

## 11. 外观与个性化（菜单「查看」）

## 13. 常见问题与反馈

- **额度什么时候恢复？** 底部状态栏和灵动岛都会显示 5 小时窗口信息；撞限流可开「无人值守续跑」自动继续。
- **缓存倒计时是什么？** 提示服务端 prompt 缓存的剩余有效时间。过期**不丢任何内容**，只是下一条消息要整段重读、多扣额度；上下文大时终端会问你要不要先压缩（见 §9「省 token 规则」）。
- **哪些事会弹系统通知？** 定时任务启动、限流后自动续跑、周限额提醒（默认开启；如需关闭，把用户数据目录下 `settings.json` 的 `notifications` 改为 `false`）。
- **数据在哪？** 会话在 `~/.claude/projects/`；应用设置在系统用户数据目录，卸载重装不影响会话历史。
- **遇到 bug / 想提建议？** 菜单「帮助 → 反馈」、输入 `/feedback`，或直接访问
  https://github.com/guoy0701/ClaudeTerminal/issues ——问题和回答公开沉淀，别人搜到就不用重复问。

### 任务队列（无人值守串行执行，v3.9.0）

自动化设置 → 任务队列。把互不相关的任务排成一队，睡前点「开始」或设定时开始：

- 前一个任务经 goal 评估判定「彻底完成」才起下一个；起下一个前先查该账号 5 小时额度，满了等窗口重置。
- 每个任务可单独设目录、模型、effort、账号、完成条件、最多续跑轮数、最长运行时长。
- 「仅一次」可以**指定日期**（v3.20.0）：比如周六就把队列设成「9 月 28 日 03:07」，只会在那天发车；不填日期则是下一次到这个时刻（周六设 03:07 = 周日凌晨就发车）。
- 定时开始分「仅一次 / 每天」（v3.12.1）：**仅一次**到点自动起跑的同时就把「定时开始」停用，第二天不会再开新标签跑一遍（手动「开始」不受影响）；**每天**才是每天到点都跑。新建队列与旧配置默认为仅一次。
- 队列可设截止时刻（之后不再起新任务）和失败策略（跳过 / 停止）。
- 多条队列各跑各的；同一账号两条同时跑会有黄色提示（会一起消耗同一个窗口）。
- 任务标签页跑完保留，标题打勾；托盘菜单可开始/停止。
- 应用崩溃重启后，未过截止的队列会从被中断的任务重新开始（新会话）。

### 睡前体检（v3.20.0）

计划「总览」上方的「准备情况」（每次保存自动重跑），核对的内容如下，适合睡前或出门前看一眼：

- **发车计划**：按时间先后列出每个定时任务和队列的**确切日期、星期、时刻**和所用账号；
- **账号**：是否存在、是否是 Claude 账号、是否真的能用（零 token 实测，令牌失效会标红）、是否「跟随官方终端」（夜里在官方终端换号会连带影响）；
- **额度**：发车时周额度是否已经重置、5 小时额度是否还满着；
- **续跑设置**：续跑开关、连续续跑次数上限、截止时刻、冷缓存策略；
- **电源**：是否接着电源。有待触发的计划、队列在跑或在等额度重置时，程序会阻止系统空闲睡眠（屏幕照常熄灭），全部结束自动放开；合上笔记本盖子仍会睡眠。

✗ 表示照现状一定跑不起来或会中途停住，⚠ 是提醒，✓ 是已核对无误。查额度不消耗 token。

### 发进既有会话（v3.9.1）

定时任务的「方式」和队列任务的「执行方式」都可选「既有会话」，用「选择会话…」挑一个正开着的标签或某目录的历史会话：

- 到点时会话开着 → 直接发进那个标签页（沿用它的模型、权限、账号）；没开着 → 恢复到新标签页再发。
- 目标正在跑 → 等它本轮结束再发，最多等「等待分钟」，超时跳过并通知。
- 缓存已过期（超过 1 小时没动、或换了账号）→ 按 §9「省 token 规则」：不到 100k 直接发，100k 以上先压再发；全局冷缓存设成「暂停并通知我」则不发。
- 选历史会话时会显示恢复的冷读 token 估算，请留意成本。

v3.9.2 补丁：
- 恢复的历史会话在没发新消息前也能被「选择会话…」选中（之前灰着点不了，原因是 sessionId 要等第一条消息后才拿到）。
- 允许跨账号：任务绑定了账号时，恢复历史会话用任务的账号（必为冷读，按冷缓存策略走）；没绑定仍用会话创建者的账号；绑定的账号已被移除则明确失败，绝不静默换账号。开着的标签仍沿用它自己的账号。
- 定时/队列（无人值守）会话里的子代理最多 1 个（配合本机 `~/.claude/hooks` 的并发上限与撞限熔断）。

同版顺带：定时任务内容框改为多行；模型下拉保证列出 Fable 5.1（存的是精确 id `claude-fable-5-1`，引擎清单里它显示为 `claude-fable-5-1[1m]`，两者是同一个模型，模型本身即 1M 上下文）。

### 会话消息列（v3.10.0）

在某个标签页里预先排好一列消息，按顺序逐条发进**这个会话**，适合睡前排好夜里自动跑。入口：**输入框右端**的「⏱ 消息列」按钮（v3.11.0 起从 HUD 会话行移到这里，任何时候都能看到），或输入 `/at`。

- 每行 = 内容（可 Ctrl+V 贴图）+ 可选「不早于 HH:mm」+ 完成判定。`/compact`、`/clear` 这类斜杠命令就是普通的一行，不做特殊处理。
- **上一条真的跑完了才发下一条**。完成判定两种：「模型判断」（默认）= 引擎空闲、没有挂着的确认卡、没有后台 shell/子程序在跑之后，由 haiku 读会话尾部判断上一条指令是否已执行完毕（不是中途停下、不是在等人回答、不是只做了一半）；没完成就等 60 秒再判，永不暂停、永不问人。「本轮结束即算」= 引擎空闲就发，斜杠命令默认用这个。
- 兜底：引擎空闲、无子程序、输出连续 5 分钟一字未变 → 按「已完成」处理（等也等不出结果），行上记「按静止判定完成」，列一定往下走。
- 「不早于」按顺序解析：23:00 启动、下一行填 07:00 就是次日 07:00。
- 运行期间该标签的权限卡 / 计划卡 / 提问卡 60 秒无人处理即自动决策（与 /goal 无人值守同款）。
- 标签关了也不影响：轮到时自动恢复该会话再发。发送失败的行跳过继续，连续 3 行失败才停。
- 快捷命令：`/at 22:30 内容`、`/at +20m 内容`、`/at 内容`（无时间）追加一行；`/at` 无参打开抽屉。
- 与 /goal 无关：不催「继续」、不续跑；与冷缓存策略无关：一律直接发，要压缩就自己排一行 `/compact`。

v3.10.1 补丁：引擎崩溃/重启/关标签时清空该标签的后台任务记录（否则收不到结束通知的后台任务会让列永远等）；当前行运行中标签被关掉 → 该行按「标签已关闭」判完，下一行经恢复路径继续，不再无限等。想真正停下请点「停止」而不是关标签。

v3.11.0：消息列改为**浮动面板**——拖标题栏移动、拖右下角缩放，位置尺寸记住下次沿用（存本机）。「开始」前若该标签账号已被标为登录失效，不启动并弹通知。

### 设定时账号检测（v3.11.0）

定时任务 / 队列绑定的账号如果登录已失效，到点就发不出去，而那时人已经不在了。所以**在设定的时候就检测**：自动化面板点「完成」保存后，会对涉及的每个账号（启用的定时任务 + 队列任务，未绑定的按默认账号）逐个做一次**零 token** 检测（起一个最小引擎进程只查订阅状态，不发消息，每个约 4 秒），面板里逐行显示结果：

- `✓ xx：账号可用` → 全部通过面板自动关闭。
- `⚠ xx：登录已失效` → 面板保持打开，该账号在账号菜单标红「登录失效」，请在「管理账号…」重新登录后再离开。系统通知也会弹一次。
- `? xx：无法判定` → 网络不通或引擎无响应，不标失效，稍后再试。

任务行账号下拉旁也有「🔍 检测账号」按钮，可以单独检测某个账号。只在设定时检测，不做后台定期巡检（人不在时提醒也没用）。

## 14. 手机远程（v3.15.0）

人不在电脑前，也能用手机看 Claude 在干什么、发指令、点「允许」。手机上打开的就是**电脑上的那个界面**（同一套消息流、折叠、工具卡、HUD、标签栏），只是按竖屏做了响应式：轨道隐藏、标签栏横向滚动、输入框固定在底部。不用装 App，浏览器就行。

### 怎么配对（一次就够）

1. 电脑上菜单 **「自动化 → 手机远程…」** 打开面板。
2. 点 **「生成配对码」** → 出现 6 位配对码（**5 分钟有效**）和一到多个二维码（每个地址一个）。
3. 手机浏览器扫码打开那个页面 → 页面提示「配对这台手机」→ 输入这 6 位码 → 完成。
4. 之后这台手机记住凭证（存在手机浏览器里），下次直接打开同一个网址就进来了，不用再输码。

配对期间 HUD 右侧会显示「📱 n」表示当前在线手机数。

### 手机上能做什么 / 不能做什么

能做：看实时输出；发消息（`/compact` 这类斜杠命令也算普通一行消息）；回答权限卡 / 提问卡 / 计划卡；切换标签页（只改手机本地，不影响电脑）；停止当前轮。

**不能做（刻意不给）**：账号管理、自动化面板、设置、选目录/文件、本地 shell。手机是「看 + 说 + 批准」，不是第二台电脑。点到这些地方只是没反应，不会出错。

### 两种连接方式

| 方式 | 地址长这样 | 前提 |
| --- | --- | --- |
| 同一 Wi-Fi 直连 | `http://192.168.x.x:47821/?host=…` | 手机和电脑在同一个局域网，端口 47821 没被防火墙挡 |
| 公网中继 | `https://你的域名/ct/app/<hostId>/` | 自己的 VPS 上跑一份中继 |

公网中继要自己部署，代码和部署说明在 **`relay/README.md`**（Node 单文件 `relay/relay.mjs` + Caddy 反代片段 + systemd 单元）。部署好之后在「手机远程」面板的「公网中继」栏填地址（如 `wss://你的域名/ct`）点「保存并重连」；也可以用环境变量 **`CT_REMOTE_RELAY`** 启动应用来指定。中继只转发数据、托管手机页的静态文件，配对和鉴权全在你自己的电脑上做，中继拿不到你的账号凭证。留空就只能同一 Wi-Fi 用。

### 断线与重连

手机页顶部一条状态条：**已连接 / 重连中 / 电脑离线**。手机切后台、地铁断网、电脑睡一会儿都不用刷新页面——恢复后自动重连并**补齐断开期间错过的消息**（电脑侧保留最近 2000 条事件）；断太久超出缓冲会自动全量重新拉一次当前状态。电脑侧连中继掉线也会自己退避重连（最长 60 秒一次）。

### 移除已配对的手机

「自动化 → 手机远程…」面板底部「已配对设备」列出每台手机的名字和最近在线时间，点 **「移除」** 即刻吊销：该手机正连着的话会被当场踢下线，下次打开要重新配对。手机丢了就来这里移除。

### 安全说明

- 没有配对码进不来；配对码一次性、5 分钟过期；连续输错 5 次锁 15 分钟。
- 每台手机一个独立 token（电脑上只存哈希），可单独吊销，互不影响。
- 局域网模式下服务监听 47821，只有能连到你电脑的人才够得着；公网模式下中继是你自己的服务器。
- 远程能调用的功能是**白名单**写死的（发消息、批准、停止、读上下文用量等几项），白名单之外的一律拒绝为 `forbidden`——即便有人拿到 token，也删不了账号、改不了设置。
